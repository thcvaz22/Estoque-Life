# AION Skill 2.0 — fallback contextual

Quando o provedor generativo externo não responder, a AION não deve voltar para uma apresentação genérica. A contingência deve usar, nesta ordem: dados internos verificados, conhecimento do sistema, análise local de gestão/mercado e contexto da tela/conversa. Perguntas de sistema como emissão de NF, senha, romaneio e veículos devem receber direção específica mesmo sem IA externa.
